# Standalone review

The whole delivery loop is not required for a single phase or bug fix. Use
`$phased-delivery` to review an existing branch or PR against its ticket or
requirement, checking the current diff, acceptance evidence, tests, scope, and
correct PR base. Preserve the project's supplied requirement and ticket links.
Run its required PR checks without creating a second delivery lifecycle.

If no explicit acceptance criteria exist, derive a short checklist from the
stated expected behavior and mark any material assumption for the owner. Do not
invent a multi-phase plan merely to conduct a review.
