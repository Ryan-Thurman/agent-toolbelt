# Approved requirements
R1: A workspace admin can invite a teammate through the existing authenticated application.
R2: An admin cannot create an invitation for another workspace.
R3: Retrying an invitation request does not send duplicate invitations.
Decisions: Use the existing application and worker. Keep the current identity provider.
Excluded: Guest accounts and billing changes.
Traffic, latency, cost limits, and retention policy have not been supplied.
Implementation is not authorized in this evaluation.
