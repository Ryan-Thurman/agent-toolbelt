# Repository Style Guide

Status: Draft | Approved

## Authority and Precedence

List the canonical owner, explicit instruction files, enforced configuration, and
the rule that representative local conventions fill gaps.

## Evidence

List configuration and representative code/test paths. Note conflicting or weak
evidence; do not make it policy until reviewed.

## Domain Vocabulary and Naming

Canonical terms, distinctions, and examples for public or cross-module names.

## Module, Error, and Comment Conventions

Only repository-specific boundaries, helpers, error handling, and non-obvious
comment practices.

## Test Conventions

Test locations, names, fixtures, and observable behavior patterns.

## TypeScript / React Supplement

Only applicable local overrides or adopted baseline references. Keep exports,
folders, state, CSS, framework boundaries, and test choices local.

## Uncertainties and Review Decisions

Questions, rejected rules, and the evidence needed to settle each one.
