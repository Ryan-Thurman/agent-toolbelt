# /pr-review-reply

Use `/pr-review-reply` to answer a human reviewer's PR threads. Use `/pr-review --comment` to post new findings.

**Arguments:** `$ARGUMENTS`

Follow the `pr-review-reply` skill (`skills/pr-review-reply/SKILL.md`). Its "Inputs" section defines each argument.
