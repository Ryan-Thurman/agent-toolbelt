# Technical health and modernization

1. Run `tech-debt-discovery` to find evidence-backed candidates across the requested scope.
2. Run `tech-backlog-assessment` for selected items to decide `Do`, `Defer`, `Reject`, or `Spike`.
3. Use `simplify`, `retrofit`, or `phased-delivery` when implementation is authorized.
4. Verify the selected result against its recorded baseline and update the debt register.

Use existing style, complexity, dependency, test, and operational evidence as inputs.
Report unavailable tools and unread areas.
Keep discovery separate from repairs.
