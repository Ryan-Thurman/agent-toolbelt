# /write-tests

Use `skills/cover/SKILL.md` for test authoring.

Use the repository's existing framework, fixtures, and commands.
Preserve supplied acceptance criteria and project requirements.
Apply tests within the user's authorized scope and the shared skill's mutation rules.
Report which tests ran and which checks remain unverified.
