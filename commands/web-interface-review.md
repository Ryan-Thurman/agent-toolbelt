# /web-interface-review

**Arguments:** `$ARGUMENTS`

Use this command to review UI code for accessibility, focus, forms, and layout rules. Use `/pr-review` for a full diff review.
Follow the `vercel-web-interface-guidelines` skill for `$ARGUMENTS`.
With no argument, the skill reviews the changed UI files, or the app when no file changed.
