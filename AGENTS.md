# Public repository content

Publish reusable skills, required references, templates, workflows, package tooling, automated checks, and essential usage instructions only.
Keep maintainer reports, project handoff documents, and evaluation material outside this repository.
Do not add `docs/` or `evals/` to commits or plugin packages.
Keep project benchmark reports and evaluation ledgers private, regardless of their directory.
Exclude credential files, authentication state, and execution logs from published source and packages.
Use ignored `.atb-work/` only for disposable local output.
Preserve durable private documents outside the repository and report their local paths to the user.
